# Junbi

วางแผนเที่ยวกับครอบครัว ใช้ฟรี ข้อมูลทุกอย่างอยู่ในบัญชี Google ของผู้ใช้เอง

- **เปิดใช้:** https://attawit43559.github.io/junbi/ (เพิ่มไปยังหน้าจอโฮมได้)
- **ล็อกอิน:** บัญชี Google ของผู้ใช้
- **ข้อมูล:** ไฟล์ JSON หนึ่งไฟล์ต่อทริป และไฟล์ตั๋ว/ใบจอง ในโฟลเดอร์ `Junbi` ใน Google Drive ของผู้ใช้ (สิทธิ์ `drive.file` เห็นเฉพาะไฟล์ที่แอปสร้าง)
- **AI:** คีย์ Gemini ฟรีของผู้ใช้ เก็บในเครื่อง เรียก Google ตรงจากเบราว์เซอร์
- **ไม่มีเซิร์ฟเวอร์:** ผู้พัฒนาไม่มีฐานข้อมูลของใคร และไม่มีค่าใช้จ่าย

## ไฟล์

| ไฟล์ | หน้าที่ |
|---|---|
| `index.html` | ตัวแอป |
| `backend.js` | กฎของทริป, ที่เก็บใน Google Drive ของผู้ใช้, ล็อกอิน, Gemini (แก้ไฟล์นี้โดยตรง) |
| `tools/link-expander/` | ตัวเปิดลิงก์ Google Maps แบบสั้น (Cloudflare Worker) และวิธีติดตั้ง |
| `guide/` | ภาพประกอบคู่มือการใช้งาน (ไทย/อังกฤษ) |
| `sw.js` | เก็บตัวแอปไว้ในเครื่อง ใช้ออฟไลน์ได้ |
| `plan-export.js` | ส่งออกหน้าสรุปทริปและหน้ารายวัน |
| `lang-en.js` | ข้อความภาษาอังกฤษ |
| `privacy.html` | นโยบายความเป็นส่วนตัว |

Google Cloud project: `junbi-513612` (OAuth client แบบ Web, redirect `https://attawit43559.github.io/junbi/`)

ไฟล์อยู่ใน Drive ของผู้ใช้ แต่การล็อกอินและโควตาการเรียก Drive API ยังผ่าน Google Cloud project ของ Junbi ซึ่งใช้ร่วมกันทุกคน

Junbi แยกจาก My Trip ทั้งโค้ด ข้อมูล และบัญชี (เริ่มต้นจาก My Trip commit `b42487d`) ไม่ใช้คีย์ Google Maps: ลิงก์ Maps ที่แชร์เข้ามาอ่านจากลิงก์ผ่านตัวเปิดลิงก์ และสถานที่ที่ AI แนะนำจะเปิดเป็นผลค้นหาใน Google Maps ให้ผู้ใช้ตรวจเอง Android ใช้ Web Share Target ของแอปที่ติดตั้งแล้ว ไฟล์ที่แชร์จะจับคู่ด้วย Gemini ของผู้ใช้และเก็บใน Drive ของผู้ใช้

**iPhone:** เว็บแอปบน iPhone รับการแชร์ตรงๆ ไม่ได้ จึงใช้คำสั่งลัด (Shortcut) ที่เปิด `https://attawit43559.github.io/junbi/?add=<ลิงก์ที่แชร์>` วิธีสร้างอยู่ในหน้าโปรไฟล์ของแอป ถ้าทำคำสั่งลัดสำเร็จรูปไว้ ใส่ลิงก์ iCloud ที่ `IOS_SHORTCUT` ใน `index.html` แอปจะแสดงปุ่ม "เพิ่มคำสั่งลัด" แทนขั้นตอน

**ชวนเพื่อนร่วมทริป:** ทริปเป็นไฟล์เดียวใน Drive ของคนสร้าง การชวนจะแชร์ไฟล์นั้นให้อีเมลของเพื่อน (Google Drive ส่งอีเมลพร้อมลิงก์ `#join-<รหัสทริป>.<รหัสไฟล์>`) เพื่อนเปิดไฟล์ครั้งแรกผ่านหน้าเลือกไฟล์ของ Google (`trigger_onepick`) เพราะสิทธิ์ `drive.file` เปิดได้เฉพาะไฟล์ที่ผู้ใช้เลือกให้แอป ต้องเปิด **Google Picker API** ในโปรเจกต์ `junbi-513612` (ฟรี) และระหว่างที่แอปอยู่ในโหมด Testing เพื่อนต้องอยู่ในรายชื่อ Test users
